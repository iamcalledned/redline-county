# Hand-authored additions

Rojo mounts this directory at Workspace.Handcrafted. Put independently authored `.rbxmx` models here. Geographic/landmark generation never writes this directory. Do not edit assets/generated in Studio and expect regeneration to preserve those edits: export them here or change the curated recipe instead.

The Town Hall and fictional garage recipe lives in geo/curated/landmarks.py. Map extent, origin and selected route live in geo/curated/hopedale.json. Neither is overwritten by imports.
